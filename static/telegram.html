🤖 StorageBot — Instalasi Manual

Telegram Bot untuk Box Storage

Kirim file dari HP ke storage langsung lewat chat, minta file balik, list folder. Page ini cuma panduan + generator script — server nggak pernah lihat token / password bot kamu.

1

Buat bot di @BotFather

Buka @BotFather di Telegram, ketik /newbot, beri nama unik. BotFather memberi HTTP API token berbentuk 123456:ABC-DEF.... — salin token-nya.

2

Izinkan bot membalas chat

Setelah bot jalan, kirim /start ke bot kamu dulu (biar bot boleh membalas kamu).

3

Isi konfigurasi

Token dari BotFather, base URL storage (misal https://box.domainanda.com), dan kata sandi admin storage (yang dipakai login di web).

Script siap


    
Jalankan: simpan sebagai storagebot.py, lalu pip install python-telegram-bot==20.8 dan python3 storagebot.py. Bisa di VPS mana pun. Tes: ketik /start & /list, kirim file apa pun ke chat — harus kesimpen ke storage.
